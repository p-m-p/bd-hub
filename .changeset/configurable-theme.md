Add configurable theming via an optional `bd-hub.config.json` in the working directory. The theme covers font (family, mono family, scale), colors (semantic token overrides), and spacing density (dense/normal/spacious), and defaults to the current Catppuccin style. Light and dark schemes can be themed independently, fixed to one mode, or replaced with a single non-reactive custom theme. Served as `/theme.css`; config edits apply on browser refresh.
