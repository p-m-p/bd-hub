Add built-in named themes: `"theme"` in `bd-hub.config.json` now accepts a built-in theme name (`"catppuccin"` or `"dracula"`) as well as a theme object. Also add a JSON Schema for the config file (`schema/config.schema.json`), referenceable via `$schema` for editor validation and autocompletion.
